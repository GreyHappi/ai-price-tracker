| D-12 | **History discipline: write `observations` only on semantic change** (`snapshot_hash`), otherwise update `last_checked_at`. `snapshot_hash` always covers exactly (`price_minor`, `list_price_minor`, `currency`, `in_stock`) for every source, with `list_price_minor` null outside OEM dual-price sources and `in_stock` tri-state (`true`/`false`/`null`). The `in_stock` nullability is pinned per source; a null ↔ non-null transition is suspicious, held, and never alerted. For OEM dual-price sources, `price_minor` is the effective advertised price (campaign when published, otherwise list), and nullable `list_price_minor` preserves the list price. A null ↔ non-null `list_price_minor` transition — a campaign appearing or disappearing — is likewise suspicious, held, and never alerted until a human accepts it. Null `in_stock` participates in `snapshot_hash` as its own state; this detects campaign start/end and list-price changes while target rules stay on the payable price. `scrape_runs` records **every attempt** (kind, lane, status, started_at, duration, error class). `change_events` = what changed; `notification_deliveries` = attempted delivery, with a unique `dedupe_key` + cooldown. **Failure bodies never enter Neon.** Primary may keep a size-capped, sanitized diagnostic body/snippet under `diagnostics/failures/` on local disk with 7-day rotation. **Amended 2026-08-24:** the initial accepted baseline, every accepted change, and every suspicious/held candidate store a sanitized, size-capped `snapshot-v1` envelope under primary's separate `snapshots/` directory (never Neon). Primary atomically installs it as `pending` before semantic effects, then reconciles its lifecycle state from the committed run before a healthy ping; a write failure blocks effects, while a post-commit reconciliation failure leaves protected `pending` evidence and suppresses the ping. Every snapshot is retained at least 35 days. Afterward, cleanup always preserves the two newest `accepted` baseline snapshots by validated UTC capture time (never ingest/`LastWriteTime`) and every unresolved `held` or `pending` snapshot; only unprotected older `accepted` and `discardable` snapshots age out. Thus held attempts cannot evict the current/predecessor evidence chain. State transitions are atomic over the pinned one-envelope-per-file layout; the size cap never truncates the extracted field or containing region; snapshots are not part of the rotating failures path. Each accepted/held candidate in one backup workflow execution contributes one root envelope file to that execution's single `snapshots-<github-run-id>-<run-attempt>` artifact with `retention-days: 30`. Its batch barrier is `prepare → upload → finalize`: prepare has no baseline/observation/event/delivery effects; a zero-envelope no-op skips upload; after upload returns id+digest, finalize independently revalidates both lease scopes before each candidate's effects. Upload failure affects the batch; a failed candidate fence produces no effects and retries from a fresh fetch, while other candidates finalize idempotently. Before a primary cycle may ping healthy, its read-only-authenticated, idempotent ingester enumerates all non-expired artifacts from the exact backup workflow, verifies the GitHub API digest, enforces entry-count/expanded-byte/path caps, validates every envelope's entry/run identifiers and payload hash, resolves terminal run state, and atomically installs each unseen snapshot under the matching lifecycle state. Failure retries and suppresses that health ping. This preserves one canonical chain when primary returns inside 30 days; a longer outage can lose already-expired evidence (far beyond D-02's <95%-uptime reopen trigger; accepted). Backup failure diagnostics may use a separate Actions artifact with `retention-days: 7`; cookies, tokens, headers, and personalized content are removed. Full unsanitized HTML is forbidden in public-repo artifacts. | Rejected: append-every-scrape history (LL; storage noise), storing raw HTML in DB, relying on GitHub's default artifact retention, uploading unsanitized pages to public-repo artifacts. | — |
